# المالك — إدارة مزرعة الدواجن

تطبيق عربي متجاوب لإدارة سجلات مزرعة الدواجن باستخدام React وVite وTailwind CSS وSupabase. الواجهة RTL، وتعمل على الهواتف والحواسيب.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. ثبّت الحزم وشغّل خادم التطوير:

   ```bash
   npm install
   npm run dev
   ```

3. أنشئ مشروعاً في Supabase، ثم انسخ `.env.example` إلى `.env.local` وأدخل بيانات المشروع:

   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

4. من لوحة Supabase افتح **SQL Editor** وشغّل محتوى [`supabase/schema.sql`](./supabase/schema.sql) لإنشاء الجداول وسياسات حماية البيانات.
5. فعّل تسجيل الدخول بالبريد الإلكتروني من **Authentication → Providers → Email**. أنشئ حساباً من شاشة الدخول (قد يتطلب تأكيد البريد وفق إعدادات مشروعك).

## الأقسام والبيانات

- متابعة الدورة اليومية (حتى 42 يوماً) مع حساب النافق التراكمي ومنع تكرار يوم الدورة.
- فواتير العلف وملخص الكميات والتكاليف.
- توريد واستهلاك أنابيب الغاز.
- فواتير الكهرباء وقراءات العداد.
- سجل العمال والأجور والحضور والغياب والسلفيات.
- المصروفات الإضافية.
- مبيعات الدواجن وحسابات التجار والمبالغ المتبقية.
- عمليات الإضافة والعرض والتعديل والحذف متاحة في الأقسام، مع بحث في السجلات.

يحفظ كل سجل معرّف صاحبه، وتستخدم سياسات Row Level Security في Supabase لمنع المستخدم من الاطلاع على بيانات حساب آخر. لا تضع مفتاح `service_role` في تطبيق المتصفح؛ استخدم مفتاح `anon` فقط.
